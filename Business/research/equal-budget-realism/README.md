# EQUAL-BUDGET-REALISM-01 — owner summary

Research recommendation; no solver runs, spend, hidden material or AX42. Optimizer implementation and registered scientific policy are unchanged.

**Compare Carbon with a competent adaptive engineering workflow, including the industry's ordinary surrogates and caches.** Random search or a weak one-node thermal model alone would make the investor comparison unconvincing.

- Battery: supported lookup/interpolation, constrained Bayesian search, and bounded direct optimization of each ambient branch. A different protocol must start from its own valid initial/age state; “warm start” cannot silently reuse an aged cell.
- Motor: direct constrained FE search with multistart/global competition, plus full-curve Kriging/RBF response surfaces and FE confirmation. Preserve torque, ripple, cogging, skew and current constraints.
- f02: exhaustive lookup for the existing finite menu; multi-input impulse-response/state-space thermal methods for new supported schedules. Test gradient/adjoint control as a strong challenger only if the continuous action law and sensitivities are actually available.
