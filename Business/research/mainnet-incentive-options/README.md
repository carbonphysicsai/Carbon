# MAINNET-INCENTIVE-OPTIONS-01 — owner summary

**Research options, 2026-10-10. No simulation rerun, spend, chain operation or policy change.**

No reward shape solves a misaligned score. First establish score-to-decision alignment, then distinguish admission, scientific promotion, artifact attribution, target weights, consensus and actual receipts. The [comparison](OPTIONS.md) gives four families and owner decisions; the [source register](SOURCES.md) separates documented practice, code, simulated counterexamples and unmeasured hypotheses.

| Option | Main attraction | Main unresolved cost/risk |
| --- | --- | --- |
| Winner-take-most | Concentrates a Challenge's budget on the demonstrated incumbent | Discontinuous near ties; weak newcomers may stop entering; extra screening identities can lock out a better later model |
| Top-k | More independently useful builders can receive rewards | Clones can fill slots; more qualification/revalidation; no Carbon top-k experiment establishes improved entry |
| Smoothed targets | Reduces abrupt target changes | Pays displaced incumbents longer; can preserve stale agreement and copying profitability |
| Time-decaying incumbent reward | Limits passive incumbent income; current testnet baseline already does this | More burn; genuine improvements may be too small to reset/replace; identity changes can try to renew the clock |

These choices overlap: smoothing and decay can be applied to a winner or a slate. Carbon's pinned `testnet-winner-v1` lists **three Challenges**, with a full first day then daily halving, and no same-hotkey/coldkey clock reset. The sims assumed an **eight-way** share; they stop at theoretical targets.

[These committed simulations](OPTIONS.md#what-carbon-has-and-has-not-measured) show exact-digest screening deduplication helps exact clones, while an over-wide near-copy filter suppresses the best model. Equal-split attribution still rewards a copier. They establish no real miner-entry response or mainnet return. #989 is the unmerged predecessor of #1007, not independent corroboration.

Options for owner review: preserve a single incumbent with a separately reviewed exact-artifact admission/attribution rule; consider a top-k slate only after evidence for useful independent runners-up; consider bounded smoothing only after measuring transition lag; reconsider decay only with entry/retention and actual receipt evidence. The note recommends the **evidence sequence**, not economic parameters.

All new budgets, k, margins, smoothing, decay, identity/attribution rules and network configuration remain **HUMAN_INPUT**. A machine-readable [options record](options.json) includes no deployable policy.
