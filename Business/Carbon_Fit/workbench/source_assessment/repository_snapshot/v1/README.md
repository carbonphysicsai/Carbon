# Repository-snapshot source assessment profile v1

This operational profile implements the Ryan-controlled, repository-pinned verification boundary for the public `periodic_viscous_burgers_1d_v1 / Dynamics` source profile.

The installed production index is intentionally empty. GOAL-WORKBENCH-06's `source_assessment/v1/` fixtures remain test-authored detached conformance material and are not admitted here. A candidate source statement can enter a later snapshot only after an exact Ryan adoption record binds its request, subject, response bytes, scope, and canonical digest.

`MATCHED_APPROVED_SOURCE_SNAPSHOT` means only that imported bytes and scope match an assessment admitted to the installed application snapshot. It is not live operator authentication, scientific qualification, a rights grant, fresh execution, score eligibility, protected reuse, or launch authority.

The browser never accepts a profile or approved index from a workspace or import. Replacing the application or release is outside this profile's threat boundary. Offline use cannot detect a later withdrawal until a newer accepted application snapshot is installed.
