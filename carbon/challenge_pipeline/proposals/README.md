# Level proposals

Graphite proposes the capabilities for every construction level of every
Challenge (OWNER-CHALLENGE-ROADMAP-03, amended 2026-10-02). One file per
Challenge and level: `<challenge>/level-<n>.json`, schema
`carbon.challenge-pipeline.level-proposal.v1`, validated by
`carbon/challenge_pipeline/proposals.py`. The construction contract owner
accepts or declines each one, and a level above 0 is reached only with an
accepted proposal. Graphite never writes the contract or an expansion record.
