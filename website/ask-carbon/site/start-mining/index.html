01 / What You Need

A Linux machine, your own wallet, and an optional agent.

A machine

Linux x86-64 (on Windows, WSL2) with git, curl and Docker. For GPU practice, an NVIDIA GPU with the NVIDIA Container Toolkit.

A hotkey

A hotkey in your own Bittensor wallet. The Control Center prepares the registration call and you sign it in your own wallet.

An inference key

Your own Engy or Chutes key, only if you run an autonomous research agent.

02 / Install and Sign

Two commands on your machine.

  1. 01

    Install and open the Control Center

    The script checks your machine, installs Carbon’s locked environment, builds the pinned images locally and starts the Control Center on 127.0.0.1. It prints the address and a session token.

    git clone https://github.com/carbonphysicsai/Carbon.git ~/carbon
~/carbon/scripts/install_miner.sh        # add --gpu for GPU practice
  2. 02

    Start your signer

    Carbon never holds or asks for your key. Every request is signed by this process, on your machine.

    ~/carbon/.venv/bin/carbon-miner-signer --wallet <wallet> --hotkey <hotkey>
