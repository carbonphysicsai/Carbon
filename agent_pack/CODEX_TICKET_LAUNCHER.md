# Ticket startup

Start with [AGENTS.md](../AGENTS.md) and the current authorized task. Follow the
[single delivery policy](../.agent/DELIVERY_PROTOCOL.md), not lifecycle templates
copied into old tickets. [EXECUTION_PROTOCOL.md](EXECUTION_PROTOCOL.md) is the
short executor-independent overview.

Verify the task's base and relevant code/specification versions. Use an approved
suitable branch/worktree; a new latest-main checkout is not required solely
because main advanced. Preserve other worktrees and changes.

Read the relevant authority and callers, implement the coherent replacement,
remove its obsolete paths, and run the applicable focused/canonical checks.
Record material decisions once. Continue authorized work without per-slice
permission or duplicate notification/receipt queues.

Use the designated delivery owner and actual current human/protected controls.
Do not waive an explicit block or reserved decision. A green software result
confers no scientific, security, economic or production qualification.
