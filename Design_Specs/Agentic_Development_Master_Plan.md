# Carbon Agentic Development Master Plan

**Status:** OWNER-CANONICAL long-horizon development plan.  
**Purpose:** connect the implemented A0–A7 foundation, the remaining A8–A12 Wave-A work, Waves B–G in `Build_Out.md`, and Carbon's longer-term generalized agentic construction, frontier, treasury, commercial, qualification, and Physics Intelligence architecture.  
**Authority:** this document owns long-horizon sequencing and dependency interpretation. `Design_Specs/Build_Out.md` remains the detailed current implementation sequencing authority for the active P0 waves.  
**Non-permission rule:** later waves are not authorized for implementation merely because they are described here.

---

# 1. Development doctrine

> **First prove the judge. Then prove the portfolio. Then deepen the physics. Then widen the search. Bring industry in throughout.**

Engineering doctrine:

> **Abstract the interface now; do not broaden execution freedom now.**

Agentic doctrine:

> **Carbon can widen what participants are allowed to discover without changing who controls the grade.**

Security doctrine:

> **Construction and official evaluation are separate security domains.**

# 3. Wave A — bounded protocol skeleton

Goal:

> prove the software authority boundaries before real scientific execution.

## A8 — TrainEval fixture execution

Scope:

- exact fixture-official request/handle composition;
- deterministic synthetic backend;
- private outcome types;
- A5-only score construction;
- explicit infrastructure/strategy/result separation;
- no public card publication inside A8;
- mechanically non-emission-capable;
- no generic `mock | official` mode;
- no arbitrary miner code execution.

Constitutional gate:

> A8 may exercise lifecycle and contract shapes. It may not be treated as evidence that the scientific backend, sandbox, truth source, or production scoring path is qualified.

## A9 — MCP surface

Integrate:

- info;
- prior;
- scaffold;
- dry validation;
- estimate;
- submit;
- submission result;
- later ratified light/mock paths.

Hard rule:

> free/practice signal cannot become a high-fidelity surrogate for the hidden exam.

## A10 — public leaderboard

Public projection only. No hidden seed, internal measurement vector, private score material, or scientific authority beyond the registered public result state.

Future compatibility:

- Challenge leaderboard is not the same object as a persistent frontier record;
- frontier promotion is a later layer.

## A11 — observability

Structured:

- state;
- failure class;
- runtime;
- retry;
- environment identity;
- redaction;
- evidence IDs where public-safe.

Never expose the hidden exam.

## A12 — invariant suite

Wave A closes only when tests demonstrate the core authority boundaries, not merely happy-path functionality.

# 5. Wave C — real single-Challenge vertical integration

Goal:

> execute one real candidate through one qualified end-to-end scientific path.

Required chain:

```text
registered Challenge
→ qualified population / SamplingPlan
→ qualified generator + truth
→ producer-independent reconstruction
→ protected evaluation
→ MeasurementContracts
→ Score Pack
→ ExperimentRecord
```

Required implementation work:

- real TrainEval production adapter;
- sandbox/container execution;
- resource controls;
- validator orchestration;
- backend/reference adapters;
- evidence receipts/provenance;
- MCP end-to-end paid path;
- testnet-capable Bittensor transport without claiming final frontier economics.

STOP-SHIP if:

- generator error is material at candidate-resolution scale;
- physical-truth oracle can be outranked because the grader rewards generator bias;
- task omits a causal input;
- all realistic strategies are scientifically inadmissible;
- winner flips under ordinary reconstruction/evaluation variance.

# 7. Wave E — Landscape and evidence memory

Goal:

> learn from authoritative experiments without allowing learned memory to become scientific authority.

Landscape may:

- ingest structured ExperimentRecords;
- represent method/context/outcome relationships;
- surface hypotheses;
- propose candidate Challenge additions/retirements/versioning;
- propose information-value experiments;
- provide priors/routing under leakage controls.

Landscape may not:

- define scientific truth;
- dynamically rewrite current Score Packs;
- change current Challenge-set allocation mid-epoch;
- alter a current frontier decision after observing results;
- expose hidden exam structure.

Doctrine:

> **Landscape proposes; registered contracts decide; independent experiments adjudicate.**

# 10. Wave H — frontier promotion and Challenge portfolio

Goal:

> distinguish ordinary Challenge ranking from verified frontier advance.

Objects:

```text
FrontierBaseline
FrontierRecord
LeaderReplacementPolicy
FrontierPromotionExam
FrontierAdvanceEvent
ChallengeSetEpoch
```

Required semantics:

- Challenge-specific scores remain non-comparable by default;
- screen ranking nominates contenders only;
- incumbent and contender use common fresh promotion evidence when required;
- decision states include `SUPERIOR`, `NOT_SUPERIOR`, `INDETERMINATE`;
- unresolved equivalence does not create an arbitrary paid winner;
- at most one paid frontier event per Challenge/window under the registered policy;
- incumbency itself earns no new performance reward.

# 12. Wave J — model-family neutrality

# 13. Wave K — generalized Agentic Construction Discovery

Goal:

> widen search from bounded training strategies toward construction methods while preserving the independent judge.

Evolution:

```text
TrainingStrategy
        ↓
ModelConstructionStrategy
        ↓
registered richer strategy graph / composition
        ↓
ConstructionProgram
```

Agent capabilities may include:

- architecture choice;
- model composition;
- loss/objective construction;
- optimizer/training curriculum;
- solver/model hybridization;
- representation selection;
- data-generation proposals;
- staged reconstruction procedures.

Hard boundary:

- construction program cannot directly access official evaluator internals;
- construction program cannot define mandatory scientific measurements used to prove itself;
- output must enter an independently controlled reconstruction/evaluation plane.

# 14. Wave L — generalized ReconstructionProtocol

Goal:

> replace the P0 assumption “fresh retraining is the only rebuild mechanism” with an explicitly registered producer-independent reconstruction contract.

Architecture:

```text
construction producer
        ↓
registered ModelConstructionStrategy / ConstructionProgram
        ↓
ISOLATED RECONSTRUCTION WORKER
        ↓
ConstructionReceipt + candidate artifact
        ↓
hard security boundary
        ↓
OFFICIAL EVALUATOR
```

`ReconstructionProtocol` owns:

- accepted construction representation;
- deterministic/randomness domains;
- resource limits;
- environment pinning;
- artifacts/receipts;
- failure attribution;
- reproducibility expectations;
- allowed external dependencies;
- isolation requirements.

Arbitrary participant code is not a default capability; freedom expands only after security and scientific qualification.

# 18. Cross-wave evidence gates

Every wave declares separately:

```text
SPECIFIED
IMPLEMENTED
TESTED
SCIENTIFICALLY QUALIFIED
SECURITY QUALIFIED
NETWORK QUALIFIED
COMMERCIALLY VALIDATED
PRODUCTION QUALIFIED
```

A later state cannot be inferred from an earlier one.

Examples:

- implemented != production-qualified;
- tests passing != scientific qualification;
- paid pilot != repeatable product;
- design-specified network advantage != empirically demonstrated network leverage.
