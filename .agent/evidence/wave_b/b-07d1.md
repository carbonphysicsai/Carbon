## Implemented contract and history

`carbon.research.prior_store` consumes the exact B-07A/B-07S `PriorPack`, refs,
channels, selectors, and authorization unions. It adds private validation
registries for the exact B-02B `ParameterCatalog`, public estimands/search
scopes, aggregate provenance, and policy identity. Validation enforces
Challenge/ref equality, canonical order, registered intervention surfaces,
same-scope counterevidence, exact `NONE_FOUND` scope/cutoff, aggregate-only
provenance, and the immutable source/publication-class ceiling.

The SQLite repository stores canonical pack bytes immutably; rejects claimed,
self, reciprocal, missing, or sequence-invalid predecessor identities; retains
authorized active/superseded history; and stops newly serving withdrawn bytes
while retaining an explicit audit-only read. Atomic index heads bind the prior
snapshot, authorization receipt, transition, history, and predecessor. Public
publication is an injected verifier seam only. The deterministic signer is
nominally TEST_ONLY.

`carbon.prior_compat` implements the private lossy v2-to-v1 mapping and an
output-hash-bound `PriorProjectionReceipt`. It is outside `carbon.research`,
defines no provider, and does not alter or install the frozen v1 lifecycle.
