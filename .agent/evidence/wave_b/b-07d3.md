## Implemented retrieval and alignment

`StaticPublicPriorProvider` serves exact active or superseded bytes only after
the stored public receipt resolves; active reads observe one atomic snapshot
and retry the complete read once before `PRIOR_INDEX_CHANGED`.
`StaticTestOnlyPriorProvider` is a separate concrete class with a nominal
private constructor, exact-ref-only selector, matching unexpired TEST_ONLY
authorization, persistent-ledger requirement, and preserved
`TEST_ONLY / NOT_UTILITY_QUALIFIED` pack content. Public and fixture paths
reject cross-channel and cross-Challenge substitution.

`StaticPriorResolver` adapts either permitted provider to B-07B's existing
`PriorResolution`, so task creation pins the exact observed index snapshot and
pack; later head movement cannot reinterpret a task. The deterministic
alignment provider reads only the authorized pack, exact public B-02B catalog,
and request Strategy. It reports structural selected-surface coverage and has
no official outcome, rank, gate, winner, qualification, or scoring output.
