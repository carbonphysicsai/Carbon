## Implemented boundary

`carbon.qualification.credibility` adds immutable, exact Challenge-bound source
descriptions, D1–D12 manifest references, claim links, responsible owners,
closed evidence category/source-kind/maturity vocabularies, limitations, and
explicit unresolved human inputs. Available sources require exact opaque refs
for the physical regime, model class, assumptions, geometry/BC/IC, method,
applicability, uncertainty, independence, validation, failure policy, and
limitations. Absent, pending, and inapplicable rows are represented without
inventing evidence.

The assessment validates caller-supplied B-06 manifests, exact canonical
identities, every claim link, category/maturity and role compatibility,
currentness, independence, ownership separation, and required human inputs. It
fails closed on missing/stale/mismatched/circular/substituted/overstated
evidence. MMS is limited to manufactured-problem code verification,
convergence, reference agreement, and limiting-case roles. Even a successful
assessment permanently reports `certifies_scientific_adequacy = False`.

The strict canonical loader rejects malformed, noncanonical, oversized,
duplicate-key, numeric, unknown-field, or trailing-input documents. The
deterministic Markdown report uses positive allow-lists for public,
independent-review, and Carbon-private audiences. Public output withholds exact
source identities and protected digests; error strings and protected object
representations do not echo hostile values.
