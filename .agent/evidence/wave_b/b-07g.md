## Implemented behavior

`LocalResearchService` exposes exactly `carbon_research_v2` and the twelve
B-07S operations: `get_challenge_info`, `get_interaction_manifest`,
`get_prior`, `get_mock_scaffold`, `dry_validate`, `compile_strategy`,
`inspect_prior_alignment`, `inspect_resources`, `forecast_resources`,
`start_research_task`, `get_research_result`, and `cancel_research_task`.
`quote_execution` is reserved but unsupported and returns
`CAPABILITY_UNAVAILABLE`. Wave-A `carbon_protocol_v1`, its official
`submit`/`get_submission_result` vocabulary, and B-07F remain separate.

The exact nominal `ExternalPublicResearchContext` and `FixtureResearchContext`
graphs select constructor-bound providers. Only the fixture graph possesses
the TEST_ONLY provider and authorization capability. B-07A owns discovery and
manifest data; B-07D3 owns prior retrieval/alignment and authorization; B-07C
owns scaffolds and the practice execution behind B-07B; A2 owns validation;
B-02B owns compilation; B-07E owns resource inspection/forecasting; B-07B owns
task state, idempotency, concurrency, polling, cancellation, records, and
terminal receipts. The dispatcher owns no duplicate domain state or semantics.

Calls and replies use the one existing canonical v2 codec. Boundary checks
enforce staged error precedence, exact nominal request/result types, recursive
forbidden controls, scalar/collection/call/reply/resource bounds, Challenge
and reference consistency, context capability, safe disclosure, and provider
failure redaction. Protected evaluator material rejects the whole result with
`DISCLOSURE_REJECTED`; no partial result is returned.

## Deterministic operation matrix

`OPERATION_MATRIX` contains one checked record for every supported operation,
including exact request/result type, semantic owner, delegate, context,
authority ceiling, disclosure class, resource/accounting class, error surface,
and prohibited cross-namespace behavior. A separate reserved record covers
`quote_execution`. Tests compare the supported records to the normative B-07S
manifest and actual dispatcher, so specification/matrix/implementation drift
fails closed.
