## Implemented fixture pipeline

`carbon.research.prior_publisher` accepts only exact immutable
`SyntheticPriorRecord` snapshots; it has no B-07B `ExperimentRecord`, practice,
Landscape, card-lake, or qualified-ingestion adapter. Eligibility excludes
mock, infrastructure, partial/unsupported, rights-ineligible, stale,
identifying, same-window, small-cell, excessive-lineage, and poisoned evidence.
Eligible records become deterministic coarsened associations with categorical
effect/support/diversity bands before the injected pack builder is called.

identities, canaries, exact effects, poisoning, material null/negative/mixed/
out-of-scope preservation, and cumulative release differences. It enforces
`evidence_cutoff_epoch + minimum_lag < activation_epoch`. B-07R-D8 fixture
authorization binds the checked content hash. One `BEGIN IMMEDIATE` transaction
appends the persistent multi-dimensional disclosure ledger, private
authorization receipt, pack lifecycle, and atomic snapshot head. Missing,
corrupt, conflicting, stale, or racing state rolls back without a partial
ledger, receipt, or index commit.

`LEARNED_QUALIFIED_OFFICIAL` branches are distinct specifications whose
activation method always returns `CAPABILITY_UNAVAILABLE` in Wave B.
