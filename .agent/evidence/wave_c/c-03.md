## Evidence contract

The required `c03-worker` CI job builds a fresh immutable image from the tested
head, emits `.carbon-artifacts/c03-worker-image.json`, and runs
`tests/service/test_c03_worker_service.py` on `ubuntu-24.04` with Docker,
Linux/amd64 and cgroup v2. Merge gate fails if a C-03 runtime change classifies
as required and that service job skips or does not succeed. Local absence of
Docker is not a passing skip.

The service campaign exercises real lab FNO and source-pinned Foundax FNO (512
points), target-free prediction, exact direct-adapter scientific-state
comparison, same-attempt checkpoint continuation, exact replay, Docker
create-response loss, network/DNS denial plus a positive canary control,
read-only root/input and scratch-only writes, kernel PID/memory/swap/CPU/scratch
limits, lower-cap denial subprofiles, external blocked-operation termination,
and descendant cleanup. Unit/invariant coverage additionally exercises closed
JSON, symlink/special/path rejection, expanded input/output and member bounds,
cross-attempt/policy mismatch, concurrent durable create ownership, immutable
late-write snapshots, quarantine and structural absence of broader authority.

## Interpretation

Each successful execution retains source/model/plan/scaling/resource/replica/
attempt/TRAIN/randomness/image/effective-control bindings and phase timings.
The CI image manifest supplies the tested wheel, lock, base, recipe, entrypoint
and final image/config identities. JUnit and workflow logs retain observed
dispositions. Public fixtures contain no protected case, credential or useful
secret.

Passing evidence earns only “implemented/tested DEVELOPMENT control” for the
exact tested head/runtime. It does not resolve global MQ-015, establish host-root
honesty, qualify protected execution or science, select a production repeat
count, establish an official budget, or authorize a real archive, reward,
network or LIVE consumer. A failed or unavailable required service capability
blocks this slice rather than becoming a skip.
