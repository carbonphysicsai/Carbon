# Wave C evidence records

Store one stable Markdown record per selected Wave C engineering ticket in this
directory. Each record maps the ticket Definition of Done to implementation,
tests, decisions, applicable automated acceptance, maturity ceiling, and
remaining human/operator inputs. Missing or unavailable checks remain visible.

Dynamic PR head, CI, and merge identities belong in the PR and completion
comment unless a later prospective authority transition reconciles them.
Evidence cannot create scientific, security, network, production, LIVE,
testnet, mainnet, transaction, weight, custody, or settlement authority.
