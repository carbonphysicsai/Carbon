## Candidate implementation evidence

`carbon.miner_mcp` composes the existing NET-2 authenticated gateway and receipt
journal, the exact A9 seven-tool service and C-07/C-01 real-path orchestration
ownership. It adds three versioned association tables inside the NET-2 journal,
with submit and bind intent durable before source mutation. A9 response objects
stay unchanged. The optional C-07 public extension is canonical, copy-on-read,
bounded by NET-2 and contains literal-false eligibility only.

Focused CPU, invariant and change-classification execution passed 69 tests on
the native Mac diagnostic environment. It covers one authenticated submit
effect, durable ambiguity without redispatch, exact controller reconciliation,
real-path-only binding, source-owned cancellation, changed-account rejection,
query-budget preservation, restart and explicit same-attempt resume, C-01 retry
continuity, response bounds and no authority upgrade. Ruff and Black pass for
the changed implementation/test paths.

One first-pass association gap was confirmed and repaired before checkpoint:
result lookup initially bound requester and submission but omitted the
Challenge. The retained query now joins the original submit receipt and requires
exact Challenge/version; the negative cross-Challenge lookup test passes.

`tests/service/test_c08_miner_mcp_service.py` uses the installed Bittensor SDK
signer/verifier, actual NET-2 gateway/journal, A9 service and a real-path
non-LIVE C-07 binding. It is wired into the existing mandatory Linux isolated
service lane. The native Mac JAX environment lacks Bittensor, so that test was
not locally collected and remains pending exact-head Linux acceptance; it is not
skipped in the required lane.

The test inputs are public/synthetic DEVELOPMENT material. They cannot become a
