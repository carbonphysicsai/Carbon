## Implemented flow

A trusted controller receives one immutable public candidate prediction and a
separately completed C-04 candidate-primary reference artifact. The closed
request binds every candidate/replica/plan/case/reference/measurement identity,
the non-unit physical parameters, grid, requested-time order, precision and
output semantics. Only read-only copied bytes enter a fresh C-03-profile worker;
no training state, reference selector, callback, scoring configuration, secret,
credential or authority store is mounted.

The worker computes four raw comparison observables and six raw physics defects.
It emits the observed candidate/reference values, raw difference, normalization
scale and normalized difference while retaining `uncertainty = null`,
`scientific_limit = null` and
`UNRESOLVED_NO_QUALIFIED_LIMIT`. A zero difference remains unresolved. There is
no ScoreInput adapter or scalar aggregation.

Output remains provisional while the worker runs. The controller snapshots the
one bounded result, records resource observations, removes the exact container,
then validates the closed finite report in a separately capped process. Exact
replay revalidates the retained bytes without another numerical execution.
