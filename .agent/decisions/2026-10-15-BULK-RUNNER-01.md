## 2026-10-15 — BULK-RUNNER-01: multi-family bulk reference runner semantics

**Authority.** Engineering choice within the solver-readiness program (lead
brief 2026-10-15). It grants no machine, spend or run. Every paid run still
needs an owner decision, which the plan names in `authority`.

**Decision.** `scripts/dev/reference_packages/bulk_run.py` is a new runner.
`triage_run.py` is left unchanged so the triage grant's behaviour cannot
drift. New schemas: `carbon.reference-bulk.run-plan.v1`, `.ledger.v1` and
`.summary.v1`. The frozen-deck manifest schema stays
`carbon.reference-triage.frozen-decks.v1`, with optional `estimate_*`
fields added.

- **Ceilings under concurrency.** A STARTED row counts the launch and
  reserves `timeout x cpus` before the container starts. A case whose
  family budget cannot cover its full timeout waits while that family has
  cases running. With nothing running, it runs clipped and is
  CENSORED_FAMILY_CAP if it reaches the clip. Allocated CPU-hours stay
  wall x cpus, as in the triage grant.
- **No retries.** A STARTED row is final. After a crash, it becomes
  ABANDONED_ON_RESUME, booked at its full reservation, and the dead
  runner's containers are killed first.
- **Packing.** First-fit in priority order, on the caps (not the
  estimates). A case that has not fit for `starvation_s` stops backfill.
- **Image identity.** The manifest pin must be among docker's identities
  for the run reference: ID, descriptor digest, RepoDigests, amd64 manifest
  digest, or the config digest from `docker image save` (needed because a
  containerd store does not name images by config digest).
- **Stats.** Recorded inside the container by a POSIX-sh wrapper, from
  cgroup v2 or v1, including on timeout (SIGTERM through `docker exec`).

**Alternatives rejected.**
- Refactoring triage_run.py: risks its granted behaviour for no gain.
- Booking an abandoned case at zero or at elapsed time: unknown, so the
  conservative reservation is booked.
- Host-side cgroup reads: cgroup paths depend on the driver and vanish
  with `--rm`.
- Strict FIFO packing: idles the machine.

**Reversibility.** New files only. The schemas are versioned, so a v2 can
add per-case limits.

**HUMAN_INPUT left.** Every machine, EUR and family ceiling value in a real
plan (the template's are HUMAN_INPUT), and the choice of provider and
instance type.
