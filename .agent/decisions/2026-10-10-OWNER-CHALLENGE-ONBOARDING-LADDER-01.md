**Decided.** Battery runs the full ladder, Levels 0 to 4, once. That run proves the
Challenge-neutral machinery. Every later Challenge then takes this path:
1. **Readiness check** (the Graphite readiness gate).
2. **One Level 0 plumbing check.**
3. **Internal Graphite Level 4:** the Constructor's baseline plus the Attacker. This
   starts the Challenge's refused-capability log.
4. **Internal Level 5:** Graphite finds every positive gain beyond Level 4. Each gain
   is audited (determinism, true-cost counting, the Level 4 attack suite) and shipped
   into the shared base image.
5. **A score proof per Challenge,** with members built at Level 4.
6. **Level 4 opens to miners** on the upgraded base image.

Levels 1 to 3 are used only to bisect a Level 4 failure.

Base-image upgrades are versioned and never change mid-competition
(OWNER-LEVEL5-INTERNAL-LANE-01): old results stay bound to their toolkit.
