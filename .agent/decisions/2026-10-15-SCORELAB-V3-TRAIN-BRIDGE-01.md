# SCORELAB-V3-TRAIN-BRIDGE-01

Status: implemented working engineering decision, DEVELOPMENT only.

The existing public coarse preparation is retained. The historical battery
`export-train` mapping is compatible but drops non-OK rows and cannot establish
the nine offered anchors' registered membership, role or raw provenance.

Add `owner_v3_train.combine` as a pure byte/document transform. Root passes
independently pinned coarse receipt, anchor-input bytes, source pins, acquisition
plan and returned-chunk manifest digests. Hash agreement establishes matched
bytes, not a signature; Root authenticates the public delivery. The PUBLIC route
requires the exact frozen nine-anchor input artifact and original TRAIN-plan
identity. Every source line maps once to an offered anchor; missing anchors get
null targets. Failed/malformed programme outputs never extend TRAIN support.

Reuse producer `_rung` and `_extract` for standard-mesh meaning and five-quantity
extraction; this introduces no measurement formula. Coarse and anchor sources
remain separately attributable. The returned receipt carries all offered
statuses and source bindings; each TRAIN row carries role/provenance references.
The existing arm excludes and counts rows with unavailable targets. No CAL/EVAL
reference, settlement, numerical adequacy, physical or qualification claim is
created. Existing prepare/export behavior and score contracts are unchanged.

The manifest schema is specific to these TRAIN anchors, not a general execution
framework. Shared worker/source-pin files are owned elsewhere and not edited.
Raw output manifests are bound after acquisition, before fitting; the anchor
inputs and cohort were frozen before outcomes. Root records actual combined
TRAIN SHA256 and constructs the default/seed11 cost probe through the existing
arm. No human scientific input is newly required by this transform.

Reversible by removing the new function and tests; existing paths retain their
behavior. No runtime, provider, hidden material, holdout or AX42 access by author.
