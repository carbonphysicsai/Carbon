# F06-MEEP-PACKAGE-01 — Meep 1.32.0 built from source, MPB library from source

**Decision.** The f06 reference image (`scripts/dev/reference_packages/meep/`)
builds Meep 1.32.0 from the upstream release asset (`meep-1.32.0.tar.gz`,
sha256 `446c589a…675b`) and MPB 1.11.1's library from its release asset
(`mpb-1.11.1.tar.gz`, sha256 `dc55b081…08e1`), serial double precision, no
MPI/OpenMP/GPU, portable flags (`-O3 -mtune=generic`, no `-march`), on the
pinned Debian base with libctl 4.5.1, Harminv 1.4.2, FFTW 3.3.10, HDF5 1.14.5
(serial), GSL 2.8, OpenBLAS/LAPACK and Python 3.13/NumPy 2.2/SciPy/Matplotlib/
h5py from the 2026-10-01 Debian snapshot (main + trixie-security). The
conda-forge fallback was not needed.

**Reasons and findings.**
- Release-to-commit: every file present in both the release archive and a
  git checkout of tag v1.32.0 (commit `95d41251…`) is byte-identical; the
  archive adds only autotools/SWIG outputs. Same check for MPB v1.11.1
  (commit `6a4fc163…`).
- Debian trixie `mpb-dev` ships headers only, no `libmpb`, so Meep's
  configure silently disabled MPB and the pregenerated SWIG wrapper then
  failed to compile. MPB's library is therefore built from source with
  `--with-hermitian-eps --without-libctl --without-mpi` (Meep build guide).
- The pinned base already carries security-updated libssl, which
  libhdf5-dev → libssl-dev requires; the trixie-security snapshot at the same
  instant is added to apt sources.
- Upstream packaging finding: the release asset's pregenerated
  `python/__init__.py` says `__version__ = '1.33.0-beta'` while configure,
  config.h and the tag say 1.32.0. The build rewrites exactly that line
  (guarded by `grep -qx` before and after); no other source change.
- `meep.simulation` imports Matplotlib and `meep.mpb` imports h5py at module
  import, so both are runtime packages.

**Alternatives rejected.** Debian's `python3-meep` 1.29.0 (wrong version);
conda-forge pymeep (unneeded, larger trust surface); omitting MPB (spec §1:
required for mode decomposition); `-march=native` (image must move to the
bulk machine unchanged).

**Reversibility.** Rebuild from the lock; nothing else depends on the image
yet. **HUMAN_INPUT left.** None for the build; an MPI build for large 3D cases
needs its own memory/observer equivalence proof (spec §1).
