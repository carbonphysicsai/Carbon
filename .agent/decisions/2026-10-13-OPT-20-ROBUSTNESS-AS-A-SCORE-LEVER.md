# OPT-20 robustness score lever: development working decision

Authority: owner-directed OPT-20 in the local optimizer queue, reviewed by
Carbon Validator. Maturity: synthetic implementation and exploratory evidence;
no Challenge score or scientific qualification changes.

The existing Score Lab toy physics trait is used in three ways against one
baseline: an explicit weighted `BLEND` term, a `GATE` limit sweep, and an
uncertainty-honesty component. The last component uses a declared toy
uncertainty-to-error-risk map on scoring and nearby scoring cells, which stand
in for outside-envelope tasks rather than defining a real envelope. It rewards
warnings on wrong predictions and penalizes warnings on accurate predictions.
The toy buyer-value path separately charges uncertainty-based decline of a
useful action. The component never receives the disjoint buyer-value cells.

Every arm scores the same frozen random-start and coordinate-neighbour slate.
The score-call count is identical, including rejected gate proposals; value
is inspected only afterward on target, shifted, extrapolated and blended
nearby tasks. The value oracle is best in this finite slate, not the global
continuous optimum. Extra wrapper CPU time is not equalized. The input file
sets all toy scales, weights, limits and uncertainty thresholds explicitly.
No curve point is a recommended production threshold.

Status remains `INSUFFICIENT_EVIDENCE` for selecting a rule. This one toy
profile has no uncertainty interval, independent held-out generator, real
robustness measurement, or Test Engineer final holdout. The Carbon Validator
owns score semantics; the owner owns any prospective adoption and values.
