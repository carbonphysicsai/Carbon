# PACKET-RECONCILE-01 — traceable clause bindings

The owner requests automatic buyer-field reconciliation. Engineering choice:
reviewed, closed selector manifests read explicit public documents; compare
typed numeric clauses or declared semantic tokens supported by exact phrases.
KEEP packet.source_path and digest provenance. Never scrape arbitrary URLs or
decide scientific authority from filenames, recency or wording similarity.

Numeric delimiters include their units/scope; no implicit unit conversion or
physical tolerance. Literal-to-token mappings are reviewed extraction rules,
not machine semantic proof. Missing, ambiguous, stale or conflicting sources
remain visible and fail the affected checklist. Explicit active decisions are
bound; history is not silently overridden. Unbound buyer fields are reported.

The output is a development consistency aid, not approval or readiness.
Alternatives rejected: unconstrained NLP approval, substring-only blanket
green, newest-file authority, or rewriting packet values automatically.
Reversal changes the manifest or removes this additive tool; packet/runtime
schemas stay unchanged. Actual source credibility/applicability and reserved
values remain with the owner/Test Lead. No new reserved value is chosen.
