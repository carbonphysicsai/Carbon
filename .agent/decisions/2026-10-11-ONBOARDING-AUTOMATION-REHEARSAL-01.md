# ONBOARDING-AUTOMATION-REHEARSAL-01 — measured consolidation, not labour inference

Run the explicitly public motor preparation workload with immutable candidate
tool heads: four packet clauses, three law anchors and one incomplete panel
draft. Control = same checker invoked separately per clause; batch = one
invocation per checker. Verify identical compared outputs before reporting
timings. Record TOOL-only entry/exit/timer events and replay retained #1116
metrics. No code/commit from another PR is copied into this main-based PR.

This tests command consolidation only. It is not historical manual-review
effort, a whole onboarding completion, strongest-cheap-baseline V4 evidence,
an independent trial or human labour savings. Missing baseline person-hours
remain unknown. Candidate source heads and source/manifest planning limitations
are explicit. Negative timing results are valid; no test forces a speed-up.

The existing source/API history remains a versioned capture, not a fresh live
status observation. New tool clocks cannot silently replace that history or
make its accepted-stage elapsed known. PREPARED events never accept a stage.
Reversibility: new versioned trials/reports, no overwrite. Owner/Test Lead
still own scientific acceptance and value; no reserved value selected.
