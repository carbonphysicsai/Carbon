# OWNER-HARD-REAL-PHYSICS-DIRECTION-01: exams must carry real, hard physics that fits cannot capture

Date: 2026-11-02 (CST), ~11:25
Status: DIRECTION from the owner, typed in the Lead session (local_87151681-c66e-4949-a26c-23c4641b5722).
Owner's words: "We just need to make the real world problem unfittable. Like the real world. We need to represent actually hard physics applied in these problems."

## Context
- Every audited king on Motor, Cooling and Ribbed Bracket is a kernel fit; the F02 2.5 king is an exact 12-constant formula.
- The strong checks and G1–G9 (OWNER-STRONG-CHECKS-GENERALIZATION-AXES-01) catch a fit that wins. This direction aims the exam DESIGN so that fits cannot win in the first place.

## Decided (direction; numeric bars stay owner picks)
- Every exam version carries a **PHYSICS HARDNESS CARD**, written by Exam Quality and receipted by the Validator. The card names the real-world features that defeat fitting and shows that each is present in the exam's cases. Candidate features:
  1. nonlinearity (material laws, saturation, temperature-dependent properties);
  2. coupling between physics (thermal–structural, electro–thermal, fluid–thermal);
  3. regime switches and onsets (yield, contact, phase change, transition, resonance crossings);
  4. history and transients (path dependence, long-horizon dynamics);
  5. high-dimensional or field inputs (geometry, spatial loads) rather than a few scalars;
  6. realistic input distributions over the real design space.
- **The rule that makes it real:** the strong checks plus G1–G9. If the best shortcut panel scores well on a version, that version is fittable and goes back to design with harder physics. It is never opened on a lighter bar.
- **Hard, but learnable:** the version must still show that a trained model can win (checks (2)–(3): headroom above the shortcuts, and a default model beating them or training that covers the physics). Hardness without learnable signal is noise, not a good exam.
- **The 4 versions in progress** (RB 2.0, BT 3.0, Motor 1.7, Cooling 1.8) each get a hardness card now. Any feature they lack is listed honestly, and the next version of that Challenge targets it.
- Higher reference-solve cost from harder physics is expected. Each spend still comes to the owner as a figure.
