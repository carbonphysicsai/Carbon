# OWNER-KOTH-CARRY-ACROSS-VERSIONS-01: the king carries over when a Challenge moves to a new construction version on the same sealed exam

Date: 2026-10-23
Status: APPROVED by the owner, directly in the Carbon Validator's session: "carries over". The owner was answering O-KOTH-CARRY: when a Challenge moves to a new construction version on the same sealed exam, does the current king carry over, or does every version bump reset the throne?
Amends: the frozen KOTH rule, for this one case only. Nothing else in KOTH changes: best score wins with the margin, and ties keep the king.

## Decided

1. **When a Challenge's served construction version changes** (for example F08 1.4 → 1.5) **and the sealed evaluation version and the active sealed pack set are unchanged,** the current king stays king. The king meets the new version's challengers under the same rule.
2. **The basis is the same exam and the same measurement,** so the scores are comparable (§7.6 holds).
3. **The king resets** if the evaluation version or the sealed pack set changes (a new exam, or a rotation), as today.
4. **Each carry-over is recorded:** king, old version, new version, evaluation version and pack-set key, so that history is never reinterpreted silently.
5. **The Ladder follows the same key,** the sealed evaluation version (see the Validator's ruling on the Ladder re-key).

## Not decided here

- The rotation rule itself.
- Mainnet weights policy.
