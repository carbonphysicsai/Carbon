# OWNER-MINER-LIMITS-EXAM-ONLY-01: only exam protection limits miners; miners see only the latest version

Date: 2026-10-21
Status: APPROVED by the owner in the Test Lead's session; the Test Lead relayed it.

## Owner, verbatim

> Remove all limits that aren't there for exam protection.

## Decided

1. **A Carbon-chosen limit on the miner or agent path is removed unless it protects the exam.** That means hidden or sealed data, seeds, private labels and references, or grading authority.
   - **External facts stay as facts, cited, not as choices.** For example, a provider's documented or observed failure point, or real hardware capacity.
   - **Validator reading, on the KEEP list:** host containment (the sandbox and parser bounds) protects the exam too, because an escape would reach hidden data and grading. So it's KEEP, with its acceptance on record.
   - **The Validator co-signs** Launchpad's combined table (`LAUNCHPAD_REFUSAL_AUDIT_20261021.md`) under this rule.
2. **The training time limit is measured** (OWNER-REBUILD-TIME-LIMIT-01, as amended).
3. **Miners see only the latest version of each Challenge.** Superseded versions are hidden from miner-facing listings.
   - Their records, receipts and evidence stay intact, and nothing already graded is rescored.
