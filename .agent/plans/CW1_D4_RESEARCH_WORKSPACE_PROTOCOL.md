`call` interface and twelve nominal operations remain available unchanged.

running/ambiguous replay is never dispatched twice.

`research-validation`. Primary C-04 calls are individually admitted and counted;
failed/ambiguous calls retain reservations and cannot trigger case replacement.

training authority by running an inner search loop. CPU/time caps remain
independently enforced; no claim is made that arbitrary source code permits
perfect semantic counting of hidden internal optimization operations.


## Cancellation latency

An active miner script or trusted practice worker observes a durable owned task
cancel flag. A worker-lifetime supervisor removes only the container whose exact
launch/owner/task intent matches. Its normal cleanup verifies absence before any
result association. Interrupted work retains its reservation until explicit
cleanup reconciliation; cancellation never grants rerun authority.

Public C-04 material preparation checks cancellation before each reference call.
An already running fixed reference call finishes or reaches its existing deadline
and cleanup before cancellation becomes terminal. It does not start subsequent
references. Cancellation-requested is distinct from cancelled/cleanup-observed.
