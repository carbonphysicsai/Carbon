## Supplied operating decisions

1. **Trust and isolation.** The first private-alpha/prospective non-paying
   testnet profile uses a Carbon-controlled, single-tenant Linux x86-64 CPU
   host. Its named administrators, kernel, Docker runtime, build path and
   supervisor are trusted. Declarative inputs and compromised numerical-worker
   behavior remain threats. Host-root confidentiality, independent third-party
   validator administration, cross-tenancy, confidential computing, GPUs and
   distributed training are outside this profile. The consequence is explicit:
   this profile alone cannot protect hidden exams distributed to independently
   administered validators.
2. **Protected-execution review.** Implement the prerequisites and prepare a
   scoped review package for the exact eventual image, controller,
   inference/reference separation, custody interfaces and trust model. Until an
   actually authorized independent reviewer is identified and supplies an
   acceptance result, protected admission remains disabled. Automated findings
   retain their origin and are not independent human/domain approval. This
   decision authorizes no assessment purchase, person-directed request or
   fabricated reviewer identity.
3. **Resources and backends.** Retain
   `carbon.c03.linux-x86_64-cpu.development.v1`: concurrency one, two eligible
   logical CPUs, 4 GiB memory/no swap, 256 kernel tasks, 512 MiB aggregate
   scratch/8,192 inodes, 600-second productive deadline, five-second grace,
   thirty-second cleanup confirmation and the existing input/output/expanded/
   member/diagnostic/descriptor limits. Record cgroup memory/CPU/PID and
   scratch/output observations as measured, bounded or unavailable; exit 137
   alone never proves OOM. Canonical `carbon_jax_lab` is the initial baseline
   and the exact Foundax profile is a distinct conformance case. No dependency
   upgrade or new architecture is selected; the absent v0.2 archive remains
   optional and unverified.
4. **Reconstruction repeats.** Select exactly three prospectively frozen
   replicas per Strategy for the new DEVELOPMENT integration profile and as the
   working rule for the first non-paying testnet profile. Each uses the same
   immutable TRAIN snapshot and resource policy with separately owner-derived
   reconstruction randomness. Retain every planned and terminal outcome; no
   best-of-three, replacement, favorable checkpoint, candidate-dependent extra
   evidence or incomplete-trio official comparison is allowed. Three is an
   owner-selected operating count, not evidence of scientific sufficiency.
   Existing authoring plans remain unchanged and the new profiles must be
   separately versioned. A scientific freeze must measure reconstruction and
   finite-case variability separately and return a prospective alternative if
   three is inadequate.
5. **Burgers and reference roles.** Keep the single Burgers Dynamics V1
   competition, registered public regimes and inactive/non-pool specialist
   reports. Public cases remain DEVELOPMENT evidence. The C-EP3 workbench keeps
   ETDRK4 as development primary and Cole–Hopf as development witness. The
   retained D-03/D-04 qualification-candidate path instead uses Cole–Hopf as

   conservative witness; ETDRK4 may be a development cross-check. Roles,
   applicability, implementation, environment, precision and numerical
   settings are explicit. Same-method refinement cannot establish independence.
   Scientific tolerances, floors, uncertainty, sample sufficiency and score
   eligibility remain with their scientific owners.
6. **Stage separation.** TRAIN material enters reconstruction only. Frozen
   inference receives the validated model artifact and exact candidate query
   fields only. It receives no reference solution, witness output, score/gate
   internals, master seed, credential or other candidate state. Reference and
   measurement execute under separate authority/storage boundaries without
   shared mutable training caches. Archive/signing authority remains with the
   supervisor. Candidate query values and private timing/error detail are not
   miner/public telemetry merely because networking is denied.
7. **Real archive direction.** Extend C-EA1 prospectively for Carbon-generated

8. **Network/economics.** Variant A, miner submission semantics,

Wave D and does not transfer qualification authority into C. Later C tickets
may consume only explicitly non-official test inputs until the gates exist.
Every mode is nominal and tests must reject relabeling or downgrade/upgrade
laundering.

## Frozen bounded integration campaign

The first new public campaign is capped at two already legal recipes (canonical
lab and exact Foundax), three frozen replicas each, six new reconstruction
attempts maximum; one exact public TRAIN snapshot; twelve prospectively fixed
development cases, one per registered cell; one worker at a time; and the

reference and measurement. There are no reserve or automatic replacement
attempts. Ordinary CI is accounted separately. Repairs require a new versioned
candidate/manifest with failed evidence retained. These counts are coverage
diagnostics, not production failure, repeat or tail guarantees.
