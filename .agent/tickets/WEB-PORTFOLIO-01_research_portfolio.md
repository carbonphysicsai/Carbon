# WEB-PORTFOLIO-01 — Investor-facing research portfolio page

Authority: owner's 3 October 2026 request in this task to build a portfolio
webpage for carbonphysics.ai explaining the selected eight research programs,
economics, expansions, industry opportunities, future fixed-resource design
competitions and rationale for company/miner resources.

Latest owner revision: keep the compact eight-card page but replace narrow
compute savings with decision/physical impact and conditional customer-scale
value. Add a future leading-model versus solver automated design contest under
fixed constraints, using a solver-side illustration now and side-by-side model
output once eligible models ship. This supersedes D2's visible economics only.

Scope: a local, reviewable static `/portfolio/` implementation in the existing
website, eight compact visual cards, source-linked proposed commercial content,
explicit conditional scale arithmetic, a labelled public numerical illustration,
an empty future model-comparison slot, deterministic additions and tests.
The source basis is `59d0fd589895557db607d228689010e65b6a33b5`; the new
commercial portfolio is a proposal and does not amend scientific sequencing,
the battery protocol lock, production economics or the adopted GTM canon.

Excluded: production publication; navigation/sitemap changes to uncommitted
live source; Ask Carbon/provider activation; telemetry; account/customer writes;
spend; live experiments; challenge activation; qualification; rewards or
emission allocation. Production authority is a distinct owner decision.

Acceptance:

- Eight programs distinguish existing bounded evidence from new task proposals.
- Each card presents the problem, highlight, industrial decision, physical
  outcome to prove, conditional value at scale, customers and concept visual.
- No long dossiers, filters, strategy sections, expansions or calculator UI.
- 25% investor-fit planning factor does not become science or emissions policy.
- No fabricated prices, market size, traction, speedup, live result or returns.
- Scale arithmetic is correct, units/assumptions are visible, no achieved gains
  or future performance targets are inferred, and no prototype quote is invented.
- Net economics includes construction, truth/evidence, deployment and upkeep;
  latency alone does not establish better decisions or operational qualification.
- Solver-only preview is an actual controlled local numerical illustration, not
  an optimization run or benchmark. No model output/winner/result is fabricated.
- Future contest names fixed bounds/constraints/resources, strong reduced/solver
  baselines, independent final-design checks and preparation/build/search costs.
- Semantic HTML is complete without JS; responsive browser/keyboard checks.
- New bytes are additions only; approved release and baseline remain unchanged.
- Focused tests plus existing website regression/knowledge checks.

Implementation: `website/ask-carbon/portfolio/`, `site/portfolio/`,
`portfolio-additions.candidate.json`, `tests/portfolio.test.mjs`.
Local output is engineering implementation/diagnostics, not qualification or
publication acceptance. See `portfolio/README.md` for tests and next release seam.
