## Goal

Resolve repository- and owner-supplied facts about the blocked C-02/C-04
inputs, run one bounded detached public numerical-reference component probe
when the recorded research scope permits it, and deliver the smallest next
owner/SciML input request. Preserve C-EP2's `COLLECT MISSING INPUTS FIRST`
recommendation unless the named missing evidence actually changes.

## Boundary

The workbench's periodic positive-viscosity Burgers source is eligible only for
public DEVELOPMENT research. Its ETDRK4 primary and Cole-Hopf witness remain
unqualified reference candidates. The probe remains detached from C-EP1 packs,
candidate evaluation, protected cases, scientific qualification, reward and
publication consumers. The archive is verified and inspected before execution;
no source is copied into Carbon runtime.

The task may add a standard-library development harness, closed frozen protocol,
focused integrity/accounting tests, public-safe aggregate evidence, and a private
raw output package. It may not implement C-02, C-04, Variant B/C, generalized
membership, waits, early summaries, answer publication, production entropy,
real archive/finality, reward behavior, network activity or LIVE operation.

## C-EP3-D1 — component-measurement semantics

Measure only operations actually executed by the pinned external source. Keep
source preparation, initialization, primary calculation, refinement, independent
witness, serialization and retrieval separate. Report a source/configuration/
hardware-scoped component observation, not an adequate-reference floor,
integrated C-EP1 exam, exams/day estimate or B savings claim. Unknown
reconstruction, compatible demand, comparison policy and B overhead remain
unknown rather than zero.
