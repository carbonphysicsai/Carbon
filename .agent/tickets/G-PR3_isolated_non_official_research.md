# G-PR3 — Isolated, non-official hosted research

**Wave:** G commercial/private/sponsored plane
**Status:** `future_reserved`; unselected and unstarted
**Goal:** Execute explicitly authorized research comparisons in a non-official evidence class and isolated resource pool.

**Prerequisites/owners:** G-PR1/2, G-PR0 instrumentation, production execution/isolation, reference/truth rights, scientific provenance, Operations/security and product owners. G-PR4 billing gate must be active before any paid dispatch.

**Scope and reuse:** Reuse qualified sandbox/reconstruction/resource-observation components where permitted, but separate identity, queue, artifacts, evidence class and deliverables from official execution. Capture exact plan/environment/context/cost/result lineage and cancellation.

**Interfaces/failure/limits:** Worker cannot run without live authorization and funds reservation. Hosted result cannot become official or qualified by relabeling. Non-essential overload cannot starve official evidence capture. No arbitrary code/data access beyond approved sandbox/source rights.

**Acceptance tests:** authorization/funds race, retry/idempotency, cancellation, sandbox escape/network/filesystem limits, resource saturation, reference entitlement, non-official labeling, provenance, customer isolation, and official-plane starvation denial.

**Definition of Done:** [ ] Exact non-official execution path passes security/ops/evidence tests. [ ] Production/security/rights activation is human-approved. [ ] Official systems cannot consume it as official evidence.

**Handoff:** G-PR4 accounts charges/refunds; G-PR5 evaluates pilot utility/economics.
