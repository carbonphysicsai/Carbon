# Wave C: Real single-Challenge integration

**Status:** PLANNED  
**Purpose:** Run one real candidate through one real end-to-end scientific path.

## What this wave is

Wave C replaces fixture-only seams with one real vertical integration: a registered Challenge, qualified population and SamplingPlan, real reconstruction, protected evaluation, measurements, a Score Pack, and evidence provenance.

## Why Carbon needs it

Contracts and fixtures can expose architectural mistakes, but Carbon must prove that one real candidate survives the full operating path under real resource, sandbox, reference, and validator constraints.

## What success means

One candidate moves through the registered Challenge, producer-independent reconstruction, protected evaluation, and ExperimentRecord chain with real adapters and testnet-capable transport.

## What it unlocks

Wave D can make the human scientific judgments required to activate the first LIVE exam.

## What it still does not mean

Wave C does not itself authorize LIVE status, broad Challenge coverage, final frontier economics, or mainnet settlement.

## Key objects

- `Production TrainEval adapter`
- `Sandbox execution`
- `Validator orchestration`
- `Reference adapters`
- `Evidence receipts`
- `Testnet transport`
