# Carbon Defensibility Register

**Status:** living diligence register.  
**Purpose:** track major Carbon claim surfaces, current maturity, and the next proof required before stronger external claims are made.

## Status vocabulary

- `CANON` — defended by canonical architecture.
- `IMPLEMENTED` — defended by code and bounded tests.
- `EVIDENCE` — defended by qualified empirical evidence.
- `DESIGN` — designed but unproven.
- `UNDER_DEFINED` — policy/mechanism not yet sufficiently specified.
- `HUMAN` — explicit owner decision required.
- `EXPERIMENT` — measured evidence required.
- `SECURITY` — dedicated security qualification required.
- `COUNSEL` — legal/counsel review required.
- `OUTSIDE` — not a current Carbon claim.
