## Maturity boundary

The publications may describe owner-recommended/specifed architecture, but must not claim:

- production-qualified Burgers;
- production treasury deployment;
- empirically proven frontier economics;
- seven Challenges already LIVE;
- subnet-wide superiority over centralized search.

## Source-control note

The canonical editable source should be source-controlled. Rendered PDF/DOCX files are release artifacts and may be generated from those sources rather than treated as normative protocol files.

The stage review is mirrored in Markdown in this directory for diffability. Paper-source archives may be stored in reproducible encoded form when direct binary/release artifacts are not committed.
