# Guarded419 target-only construction bridge

DEVELOPMENT construction only. This is the nine-anchor support/default-model
probe, not the final eighteen-model cohort or a completed score-value result.

The prospective T9 producer authenticates raw bytes, source, the actual G0
receipt and all nine offered jobs. It recomputes the shared operative guard
against each job's real currents and switch voltage. Its private-construction
`ValidatedT9Evidence` is the only input accepted by this consumer. The original
first-triple binder and historical coarse TRAIN path keep their meanings.

## Pure consumer API

```python
from scripts.dev.score_lab import guarded419_train

prepared = guarded419_train.build(
    validated_t9_evidence,
    expected_binding_digest=root_bound_t9_binding_digest,
    expected_manifest_digest=root_bound_delivery_manifest_digest,
    scope="PUBLIC_DEVELOPMENT",

support = guarded419_train.probe_support(
    prepared,
    expected_receipt_digest=root_bound_prepared_receipt_digest,
    evaluation_inputs=root_bound_sixty_input_only_rows,
    expected_inputs_digest=root_bound_input_inventory_digest,
    scope="PUBLIC_DEVELOPMENT",

kit, train, support = guarded419_train.load_probe(
    prepared,
    expected_receipt_digest=root_bound_prepared_receipt_digest,
    evaluation_inputs=root_bound_sixty_input_only_rows,
    expected_inputs_digest=root_bound_input_inventory_digest,
    scope="PUBLIC_DEVELOPMENT",

```

Digests bind exact inputs; they are not signatures or independent proof of
custody. Root independently binds receipt/delivery identities and performs all
project execution. This library neither acquires inputs nor solves or fits.
It has no filesystem access. `load_probe` loads bytes using the existing
`carbon_arm.load_train`, after the technical minimum and support checks pass.
Missing upstream code refuses explicitly rather than accepting another path.

The input inventory is a list of exactly sixty unique physical input mappings:
`c1`, `c2`, `switch_v`, `cooling`, `ambient_c`, `soc0`. It contains no reference
values, model predictions or requirement outcomes. Root projects and pins it
from the registered input-only inventory; this consumer does not fit or inspect
EVAL truth. Synthetic fixtures may use smaller inventories and cannot become
public construction evidence.

## What is admitted

A label requires both operative full-programme tracking compatibility and the
existing five-quantity producer's `EXTRACTED` result, with all outputs finite.
The tracking report must have checked all 181 phases. Every offered job is
emitted in source order. A missing, failed, partial, nonfinite or incompatible
reference row has null outputs and an explicit sidecar state. Infrastructure
failure remains `FAILED_INFRA`; it is not a model's scientific failure.

Finite high temperatures, negative plating margins or poor retention remain
construction examples. Selecting only buyer-feasible examples would bias the
training set. The strict reference voltage/fidelity contract is a separate
admissibility condition; a reference that fails it cannot supply trusted labels.
No zero filling, redraw, replacement or extrapolation override exists here.

The six-feature/five-output map, scaling bounds and trainer come from the
existing battery-v3 kit. A new TRAIN schema, context-bound kit ID and
probe-specific model ID distinguish guarded419 construction from old 4.2 data.
The old 390 rows and eighteen models are not read, modified or relabelled.
Compatibility is established by raw evidence validation, not the schema name.

## Support and next execution

Only admitted construction labels extend observed ranges or cooling categories.
At least two rows is the existing loader's technical minimum, not a predictive
quality threshold. All sixty fixed physical inputs must pass this marginal
range/category check before Root fits the default model. A failed extreme anchor
may therefore withhold the fit despite the presence of other finite labels.
The readout explicitly does not establish joint support or model accuracy.

Root can then use the unchanged existing trainer with the registered default
recipe and seed 11, record fit cost and all sixty predictions/abstentions, and
retain the fitted artifact. Training normalization is computed from this
admitted construction set only. A T9 probe is separate from the later fixed
eighteen-model cohort. This bridge does not implement T128 acquisition or its
105/23 construction/validation split; that prospective extension must preserve
the separate validation role and never pass it into fitting or normalization.

New reference adequacy, full CAL15 release, final cohort commitments, EVAL,
N1 alignment, holdout and rule adoption are subsequent stages. There is no
scientific qualification, production score, reward or LIVE effect here.
