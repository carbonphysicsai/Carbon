## 5. How to execute

### 5.1 One-time setup on a fresh machine
```bash
# repo + env
git clone https://github.com/carbonphysicsai/Carbon && cd Carbon && git checkout claude/compassionate-curie-yt9dxx
uvx --from 'uv==0.12.7' uv sync --frozen --group dev --group science-jax
# RunPod operator config (never commit; key never printed)
mkdir -p ~/.runpod && umask 077
printf '%s' "$RUNPOD_API_KEY" > ~/.runpod/api_key
printf '{"ceilings_usd": {"reference-solvers": 25}, "balance_floor_usd": 15}\n' > ~/.runpod/campaigns.json
.venv/bin/python -m scripts.dev.exam_design.runpod.pod_control --campaign reference-solvers start --cap-usd 25
# Local Docker (only for local checks); if Docker Hub rate-limits:
echo '{"registry-mirrors": ["https://mirror.gcr.io"]}' > /etc/docker/daemon.json && dockerd &
```

### 5.2 Launch a pod plan, collect, delete
```bash
# KIND: elmer | calculix | openfoam2506 ; REF: a pushed commit containing the plan
.venv/bin/python -m scripts.dev.exam_design.runpod.pod_control --campaign reference-solvers \
  dispatch-solver KIND --pod-plan docs/development/evidence/reference-solvers-2026-10-15/plans/PLAN.json \
  --vcpu 16 --minutes 120 --memory-gib 32 --flavors cpu5c,cpu3c,cpu3g,cpu5g --ref REF --max-pods 4
# -> {"pod_id": ...}; then (keep this running until it returns; it deletes the pod):
.venv/bin/python -m scripts.dev.exam_design.runpod.pod_control --campaign reference-solvers \
  collect docs/development/evidence/reference-solvers-2026-10-15/DEST --pod POD_ID --wait --poll-s 120
# emergency stop:
.venv/bin/python -m scripts.dev.exam_design.runpod.pod_control --campaign reference-solvers terminate --pod POD_ID
```
Stock is intermittent ("no ... in stock"): retry every minute. Commit the collected
`DEST/` and `accounting/ledger.jsonl` (public events only; rates stay in `~/.runpod`).

### 5.3 Reading results
Each step writes `DEST/out/<step>/step.json` (`status`, `why`), `deck-verification.json`
(per-case digests incl. `host_regenerated`), `ledger.jsonl` (per-case outcome, CPU-s, peak memory)
and the family judge's verdicts (e.g. f17 D2, f08 V9 bank-mesh gate). `setup.log` contains
`SETUP FAILED` if the native build broke.

### 5.4 Gotchas (all hit today)
- **Pods only receive files the plan names.** Add a top-level `"ship": [...]` with every
  `carbon/...` module the pod scripts import. Verify in a clean Python with no editable Carbon:
  `python3 -m venv /tmp/cleanpy && /tmp/cleanpy/bin/pip install numpy scipy`, copy the shipped
  files to a temp dir and `PYTHONPATH=<tmp> /tmp/cleanpy/bin/python -c "import <module>"`.
- **Pinned manifest must match the current case command.** If a family changes its command,
  re-freeze (e.g. `python scripts/dev/reference_packages/calculix/f08_freeze.py --out DIR`) and pin the new manifest.
- **Mesh files differ on AMD pods**: list them in the step's `host_regenerated_files`.
- **`ccx -v` exits 201** on success (handled in the calculix kind).
- **Collectors must outlive the pod's run** — if the controlling machine restarts, rerun
  `collect --wait` before the pod's deadline or the results are lost when it self-terminates.
- The dev container restarted twice today; background agents and collectors die with it.
