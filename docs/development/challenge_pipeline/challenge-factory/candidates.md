## Transparent, conditional ranking

L = useful learnability, A = advantage over strongest cheap workflow, H = room
for competition, each an **ordinal ASSUMPTION 1–5**, not a measured probability
or pilot threshold. W = min(L,A,H)/5 prevents easy learnability compensating for
no cheap-method advantage. Priority = W × base V2 × base V3 / base active
engineering days. This is a **commercial planning heuristic**, never a Carbon
score, admitted rank, ROI or forecast. Actual incremental value/advantage can
be zero for every row. Evidence replaces the hypothesis; it does not inherit W.

V2/V3 are **conditional cohort ASSUMPTION** estimates of potentially avoidable
buyer effort and job cadence, not actual sales/market volume or model savings.
C2 is retained **estimated node bank startup**, not labour/rights/witness quotes,
and not a proved ≤€100 bill. All dates/days below are ASSUMPTION low/base/high
active engineering workdays (8 h each), conditional on an applicable kit and
available inputs. They exclude waiting, native execution, accepted stage exits,
security/qualification, Graphite and the family's one-time bootstrap. Actual
brief-to-TESTED calendar time remains UNKNOWN; don't promise customer delivery.

## Deliberate exclusions / bootstrap cost

calibration/rights are open. It is not promoted from a discovery G6 failure by
ignoring process history. Compliant gripper D071's SOFA route is not one of

not a free reuse claim. B006's electrostatics route is likewise not covered
by a heat/Helmholtz MMS. D001 overlaps battery and is not a new candidate.

The kits themselves require one-time work before the conditional per-row
estimates apply: heat/electrochemistry/magnetics **2/5/12 active days** each,
structures/acoustics/CFD **4/10/25 days** each, photonics **5/15/35 days**
(all ASSUMPTION). These include applicable observer/templates/integration,
not accepted qualification, native solver time or owner waits. Allocate common
effort **once**, not to every recipient. Candidates may need expensive new
features beyond those estimates; an unresolved feature blocks reuse. Budget
pilot first, then re-estimate; do not authorize ten banks from this list.
