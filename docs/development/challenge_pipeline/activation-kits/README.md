**CUSTOMER-ACTIVATION-KITS-01 / DEVELOPMENT / SPECIFIED.** Source snapshot:
main `5fbac3099eaae368b23d266cce31ed7409685722`, 2026-10-10. These are
customer-data **designs**, not four runnable or qualified products. The goal
is to prepare an intake in days once adequate inputs exist; that outcome has
not been demonstrated. No solver runs, spend or customer outreach.

Start with this shared checklist **and** the relevant full-job extension:
[warpage](warpage.md), [solenoid pole](solenoid-pole.md),

holds its affected claim; a gap report may still be prepared. A substitute
requires named buyer/science acceptance and a smaller explicit claim, never
an automatic conversion of the original job into an easier benchmark.

## 1. What the customer must supply

These stable input IDs instantiate [#984's intake](../../../../Business/research/intake-spec-and-quote-model/INTAKE_AND_QUOTE.md).
The **proposed** readiness tests are not run results. For every item supply a
manifest entry with filename/digest, version/date, origin, responsible role,
units/support, uncertainty, confidentiality/license and allowed recipients.
Keep confidential files outside this public repository. Receipt/hash matching

## 2. What Carbon supplies

Prepared now: source-linked packet, intake checklist, gap/action log, proposed
reference/build/panel contracts and strongest-baseline comparison plan.
Conditional later work: normalize authorized inputs into a frozen case/output
contract; Data Collection packages and verifies the adequate reference;
independent owners judge feasibility, contested boundaries and reference
credibility; compare exact lookup/cheap workflow/Carbon at matched safety and
equal total budget; render versioned evidence and adverse findings.

Target reference credibility is **Tier 2** (matched buyer-tool witnesses),
earned tier **NOT_DEMONSTRATED**. Exact buyer-tool Tier 1 applies only when
reference really is that tool at those settings. Representative internal
reference-relative evidence is not buyer-tool Tier 1. Tier 3 needs applicable
experiments; no “matches reality” claim before that evidence is accepted.
Private/VPC/customer-hosted/air-gapped delivery remains a technically and
contractually qualified future mode, not something these kits implement.

## 4. Deliverable and acceptance

Reuse [#966 renderer](../../../../Business/research/deliverable-generator/README.md)
and [D01–D11 framework](../../../../Business/research/deliverable-framework/FRAMEWORK.md):
intended use; requirements; applicability P/Q/w; reference identity/credibility;
requirement-by-stratum validation; uncertainty; discovery provenance;
artifact/runtime/provenance; deployment/fallback; limitations/change triggers;
audit trail/rights. Include JSON + readable report, immutable source ledger,
typed adverse findings and explicit EVIDENCED/PARTIAL/GAP coverage.
Model/container/weights/recipe are included **only if** actually produced,
rights-cleared and accepted; currently their identity is HUMAN_INPUT.

The existing generator has no source adapter for these four full jobs. A
human-completed template/gap record is ready to draft; a complete automatically
populated EvidenceAudit/decision product is not. Eligibility and customer
acceptance are separate from document completeness. NASA/ASME/JEDEC rendering
is not accreditation, standard compliance or product qualification.

## 5. Costs, quote boundary and stop conditions

[#984](../../../../Business/research/intake-spec-and-quote-model/INTAKE_AND_QUOTE.md)
defines consumed cost, elapsed time and evidence quality separately, **not a
price list**. Cost components: authoring; rights/data; reference integration;
cases/controls/refinements/failed attempts; baseline; construction/search;
independent validation; integration; network; retention/support/lifecycle.
Use `setup + sum(N_tier * t_tier / (p_tier * eta_tier))`, measured concurrency
and effective occupancy, with correlated RAM/time and no retry double-count.
Licenses, currency/rate date, billing/idle/transfer and tax stay explicit.

Each kit retains inherited **ASSUMPTION reference-bank component** ranges,
not all-in fees or grants. Staff effort above is not priced because the
commercial rate and scope are HUMAN_INPUT. Reference setup/calibration, buyer
tool license/witnesses, model construction and support are UNKNOWN.
**All-in consumed cost and customer price: UNKNOWN / NOT_QUOTABLE,
low/base/high null/null/null.** Negative evidence can be a valid agreed gap
delivery; no sale depends on manufacturing a favorable scientific result.

Owner must choose SOW, exact price/cap, rights/privacy mode and acceptance;
science accepts limits/reference/evidence; compute accepts any dispatch.
Stop affected work for incoherent data, unresolved safety, absent rights,
inadequate reference, unaffordable evidence or unqualified delivery topology.
Do not downgrade full physics, relax safety, infer permissions or publish
customer data to make the timetable/cost fit. Independent preparation can
continue. No hidden material, runtime registration, spend or recurring pings.
