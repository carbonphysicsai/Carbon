# f08 — a reusable modal library is the incumbent to beat

**DEVELOPMENT / SPECIFIED; performance NOT_MEASURED; acceptance HUMAN_INPUT.**
[Shared comparison](README.md); [return checklist](data-collection-return.md).
Buyer: [linear support packet](../round1/f08-resonance-structure.md).

## Buyer decision and incumbent

Choose geometry minimizing worst-band tip compliance, with mass<=0.45 kg,
static compliance<=0.03 mm/N and dynamic peak<=0.15 mm/N over 80–600 Hz at
every required damping condition. No strength/fatigue, joint nonlinearity or
machine-throughput claim. Geometry changes, not frequency queries alone,
define new physical acquisition.

Strong incumbent: **geometry-specific cached static/eigen/modal library**.
For each eligible support acquire mass, static compliance, modes, modal
participation and observer projections; reuse them for damping/frequency/
supported-requirement sweeps under the same linear boundary model. Retained
mode algebra and adaptive peak search answer subsequent questions cheaply.
CLOSED_BANK can cache complete qualified FRFs directly. NEW_SUPPORTED adds
ordinary geometry-to-observable/modal interpolation only with independent
whole-geometry witnesses and tracked modes; it cannot reuse one geometry's
eigenbasis as if a different geometry had already been solved.

## Method basis and reuse

[CalculiX's manual](https://www.dhondt.de/ccx_2.20.pdf) documents eigenmodes,
modal damping and steady-state dynamic analysis. The
[Ansys mode-superposition workflow](https://ansyshelp.ansys.com/public/Views/Secured/corp/v242/en/ans_str/Hlp_G_STR4_MODESUPER.html)
supports the same industry reduction class. These are method capabilities,
not accepted Carbon damping/material laws or measured library speed.
KEEP the packet's analytical beam/oscillator and static/modal refinement
rungs. REFERENCE-PACKAGES-01 owns actual CalculiX/CAD/mesh/element/deck pins;
library, truncation and peak-search executable/data pins remain HUMAN_INPUT.

## Witness and decision checks

Use independent public/retired whole supports including rib/relief extremes,
near-static/mass gates and narrow low-damping resonances. Preserve both complex
probes, phase convention and all damping settings. Recompute modal basis for
new geometry; test omitted high modes, mode crossings and static residual
contribution rather than smooth/interpolate peak amplitudes blindly. Frequency
steps retain the packet's resonance bracketing/refinement policy. Mode count,
mesh and frequency convergence are separate checks.

Report full FRF pointwise errors, peaks/frequencies/phases, hard verdicts,
best/equivalent geometry and **mm/N regret**. A missed resonance is not made
safe by good off-resonance error. Unsupported clamps/loads/damping or nonlinear
contact need another contract; do not add them to rescue surrogate leverage.

## Cost, stop condition and credibility

Owner-reported modal **40–110 CPU-s** is existing C1 context, not a complete
three-damping/refinement bank cost. Measure novel-geometry static/eigen setup,
cached query, adaptive peak search, load/storage and verification separately.
Reuse the same design menu for both arms. Include acquisition amortization:
never bill an eigen solve on each frequency to inflate the incumbent cost.
If this already answers in buyer-acceptable time with equal decision quality,
V4 can fail even when Carbon predicts quickly. Tier 2 against matched
Mechanical/NAFEMS and task witnesses remains a target; no physical stage claim.
