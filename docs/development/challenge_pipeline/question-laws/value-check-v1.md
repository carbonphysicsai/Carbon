For an already registered uncertainty policy, an interval wholly admissible
is PASS, wholly outside is FAIL, a crossing is NEAR/unresolved pending
refinement. Show the producer's actual class definitions. The current
Cooling acquisition search uses a **working** +/-2-K near band and includes
NEAR in its reported resolved denominator. That is not a universal numerical
policy or certified interval. Return strict PASS/(PASS+FAIL) as well as the
study fraction and unresolved/NEAR rates; neither may omit difficult cases
to get into 20–80%. Minimum inventory/coverage remains HUMAN_INPUT; one pass
and one fail among a tiny or mostly unresolved bank is not sufficient evidence.

Do not turn a tie-break-only ID change into value. Report the incumbent
best-anchored equivalence set and regret, independently of deterministic
tie-breaking. Continuous requirement variation does not guarantee winner
variation. Conversely a task may legitimately give NONE_FEASIBLE: report
it without redrawing. A law/bank that fails the value prerequisite is held
for prospective revision, not purified of its unfavorable questions.
Reference failure is missing evidence, not a scientific candidate failure.

The checks are not four independent statistics **per one fixed stratum**:
A/B are per-stratum, C is their common-action intersection, D compares
strata/draws while covering every stratum. Battery's complete action is its
five-band map, with a different protocol/cooling choice allowed per band;
C does not reinstate the superseded shared-protocol restriction. All bands
still meet their own hard gates. f02's complete action may likewise be the
declared scenario-indexed schedule. Unsupported dynamic Motor roles do not
become measured strata by repeating a static curve.
