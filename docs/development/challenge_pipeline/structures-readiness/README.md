## Generators, identities and reuse

`carbon.challenge_pipeline.structures_readiness` accepts a closed digest-bound
public or isolated synthetic registration: six packet coordinates, exact
quantization, separate P/Q/w, authority and complete pins. No default population
or launch ID is installed. The packet's uniform three-damping P and weights
are development assumptions; diagnostic Q need not equal them. Recommended
optimizer snap is not silently adopted. Invalid/off-lattice shapes fail closed.
Own public seeds are unrelated to official draws; these tools never load banks.

`case` binds image, mesher, source deck/proof, synthetic Al-like material,
observer, geometry, damping and mesh/mode rung. `panel` deduplicates physical
acquisition identities against explicit completed **and** scheduled inventories:
changing P/Q/w registration does not renew an identical solve. A shared
static/eigen acquisition across damping is charged once only with exact pins;
every harmonic curve/failed process and independent refinement is recorded.
Current package batches static/eigen/three dampings in one process; five physics
stages do not mean five paid launches. Never count one frequency as one buyer task.

`train_plan` excludes the **whole geometry** across all damping and refinement
rungs. `kit_hook` checks full registered grammar, all three dampings, band,
pins and all signed observables, not just a kit name. Plans remain unregistered
until Data Collection supplies durable main manifests and kit/TRAIN receipts.

80–600-Hz coverage, all retained eigenfrequencies, mass and static tip response,
case identity and `exp(+i omega t)` convention. Near each retained in-band
resonance require <=one tenth of its half-power bandwidth. A coarse grid
remains UNRESOLVED even if every sampled point looks safe. Missing signed
probe/phase or image/source mismatch is invalid reference evidence, not a
candidate scientific failure.

Without a science-accepted case-bound numerical receipt, verdict is UNRESOLVED.
Accepted uncertainty covers mesh, retained-mode truncation, static residual,
frequency search and observer mapping; the caller must retain its actual receipt.
The hash is not acceptance by itself. Close calls remain unresolved.

development contract, never qualification or a bank's NONE_FEASIBLE claim.

feasible; a safe high-damping curve cannot compensate low-damping failure.

or safety threshold is relaxed. When adapting old exports, use retained tip
