Axes are frontier technology, investor appeal and miner appeal, each ASSUMPTION 0–5 with the same ±1 range. Frontier: 0 mature catalogue sizing, 3 advanced integration, 5 new architecture. Investor: 0 unclear job, 3 repeated engineering workflow, 5 compelling expansion hypothesis, with no TAM/traction claim. Miner: 0 inaccessible/prohibitive, 3 bounded moderate-cost job, 5 open inexpensive geometry with multiple viable methods. Excitement is the mean base axis score, with its own clipped ±1 range.
