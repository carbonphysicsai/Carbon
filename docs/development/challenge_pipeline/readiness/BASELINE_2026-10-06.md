## Why the non-passing items are not passing

Details and evidence per item are in each challenge's report file. Summary:
- Several NOT_BUILT items became wirable after their PRs merged (A1 #637, A4 #615, P3/P4 #606, S5 #613, R5 #612); the gate was not yet wired to them at this run, so the baseline measures the gate as wired at main, not the underlying readiness. A wiring PR follows; later runs append to the history.
- NOT_BUILT items name an owner and the missing PR or test in their detail; none is stubbed to PASS.
- R1 FAILs on this host: `phase4 prelive` fails closed at the carrier containment probe because no analysis image manifest (Docker and the pinned image) is available; motor has no phase-4 grant bound by the runner.
- R3 fails for the CPU carrier lane until the host supplies the pinned image manifest (`CARBON_READINESS_CARRIER_IMAGE_MANIFEST`); motor's pod lane is TBD.
- P2 (motor): scoring is registered but no Interface v1 validator adapter is recorded.
- A5 (cooling): `cooling-candidate-fault-v2` is not registered; the missing review also counts.
- V1 and V2: no Q1 report is recorded for any challenge yet.
- REVIEW_REQUIRED items (O1, S4, V3 and others) wait for the Test Lead's committed review files.
