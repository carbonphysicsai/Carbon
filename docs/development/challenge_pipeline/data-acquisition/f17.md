# f17 passive micromixer — data acquisition plan (DEVELOPMENT)

Sizes are delegated DEVELOPMENT values (F17-SCIENCE-VALUES-01 §P). One case = one
groove design's complete nine-condition panel (mesh + 3 flows + 9 scalars, 12 solver
starts) in one container launch of the pinned `opencfd/openfoam-default@sha256:020e00e5…`
image; `Allrun` is plain bash and runs unchanged on a native pod with that image.
Machine-readable: [`f17.json`](f17.json).

Cost basis: primary rung 0.18 CPU-h/design (measured locally, peak 0.5 GiB); refined
rung 0.68 CPU-h/design (extrapolated, ~1.5 GiB; measure at the pod stage). Add ×1.5 contingency.
