# Wave L: Generalized ReconstructionProtocol

**Status:** PLANNED

**Map ref:** `WAVE-L`

**Purpose:** Run construction in an isolated producer-independent reconstruction plane.

## Sequence

- **Predecessor:** Wave K
- **Successor:** Wave M

## What and why

Wave L replaces the P0 assumption that fresh retraining is the only rebuild mechanism with a registered ReconstructionProtocol and isolated construction workers.

Richer construction methods require explicit resource, environment, dependency, artifact, failure, reproducibility, and isolation contracts before they can produce candidates for official evaluation.

## Success and unlocks

An isolated worker turns a registered construction representation into an artifact and ConstructionReceipt, then hands the result across a hard boundary to the evaluator.

Secure support for broader construction programs and model families.

## Authority ceiling

Planning and compatibility context only; this wave is not active implementation authority.

## Still unavailable

Arbitrary participant code is not a default capability. Carbon widens execution freedom only after security and scientific qualification.
