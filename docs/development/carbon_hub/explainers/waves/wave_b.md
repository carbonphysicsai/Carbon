# Wave B: Science-ready authoring skeletons

**Status:** ACTIVE

**Map ref:** `WAVE-B`

**Purpose:** Make one scientific exam authorable and the miner research loop executable with fixtures.

## Sequence

- **Predecessor:** Wave A
- **Successor:** Wave C

## What and why

Wave B defines the contracts and fixture implementations needed to describe the physical job, generate canonical cases, register truth, define measurements, compile strategies, bound resources, run nominal research and practice, issue receipts, stage priors, and assemble qualification evidence.

A real Challenge needs an exact scientific object before Carbon can reconstruct and evaluate a real candidate. Wave B removes ambiguity from the exam and research interfaces while keeping unqualified behavior unavailable.

## Success and unlocks

Carbon can demonstrate the board's fixture-only chain from public scientific contracts through a resolved plan, nominal practice and research records, a fixture-official reconstruction path, TEST_ONLY prior handling, and a dossier that still fails closed for LIVE.

Wave C can connect one real candidate to one real, qualified single-Challenge execution path.

## Authority ceiling

Active only for work selected by the controlling board and ticket. Unselected work and later-wave behavior remain unavailable.

## Still unavailable

Wave B does not include real miner training, production reconstruction, authenticated remote transport, official scientific evidence, LIVE activation, network weights, or learned public priors from official outcomes.
