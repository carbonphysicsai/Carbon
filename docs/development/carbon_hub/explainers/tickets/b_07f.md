# B-07F: Fixture-official construction adapter

**Wave:** B

**Map ref:** `WAVE-B/B-07F`

**Status:** DONE

**Target phase:** WB-3/4

## What and why

Connect a ResolvedConstructionPlan to fixture-official reconstruction through the unchanged v1 lifecycle.

Wave B needs one explicit adapter that proves the compiled plan can enter the existing bounded lifecycle without hiding integration inside a gauntlet or closeout ticket.

## What it adds

A separate provider that compiles through B-02B, checks B-02C, consumes one registered canonical lever, performs deterministic fixture-only construction and held-out measurement, scores through A5, and emits private exact receipts.

## Placement and handoff

- **Depends on:** B-02B, B-02C, B-03, B-04, B-05, B-07S, A7, A8, A9
- **Feeds:** B-E4, B-GATE
- **Driver:** Codex + SciML
- **Review route:** Protocol + science + security
- **Master questions:** MQ-004, MQ-005, MQ-008, MQ-015, MQ-024

## Explicit non-goals

It does not implement production reconstruction, arbitrary code, real training, scientific evidence, or emissions.

## Current stage

PR #97 accepted and normally merged the fixture-only resolved-plan adapter. B-07F is done only in bounded TEST_ONLY engineering scope.

## Maturity ceiling

SPECIFIED, IMPLEMENTED, and TESTED are prepared only for fixed synthetic fixture plumbing. Real reconstruction, scientific/security/rights qualification, production, and LIVE remain unearned.
