# B-03: Generator API and fixed-viscosity Burgers fixture

**Wave:** B

**Map ref:** `WAVE-B/B-03`

**Status:** DONE

**Target phase:** WB-1/2

## What and why

Define and implement the generator API plus one structural fixed-viscosity Burgers fixture with exact case, attempt, outcome, accounting, conformance, provenance, and disclosure boundaries.

Downstream truth, measurement, dossier, practice, and reconstruction work needs a controlled source of canonical Challenge cases. The generator must record what it intended, what it produced, and why any case was rejected or replaced.

## What it adds

The canonical case-generation seam for the first bounded Wave B fixture.

## Placement and handoff

- **Depends on:** B-02A
- **Feeds:** B-06, B-07C, B-07F, B-GATE
- **Driver:** Codex + SciML
- **Review route:** SciML + statistics + protocol
- **Master questions:** MQ-002, MQ-003

## Explicit non-goals

It does not choose production sampling values, provide real entropy, qualify the generator, define reference truth, or activate LIVE behavior.

## Current stage

B-03 is done only in bounded merged engineering scope. PR #69 preserved the exact reviewed tree; exact-head CI and Greptile, exact-main CI, and the issue #42 closeout are recorded in authority.

## Maturity ceiling

SPECIFIED, RATIFIED_ENGINEERING_CONTRACT, IMPLEMENTED, TESTED, GREPTILE_REVIEWED, and MERGED are earned only for the bounded fixture implementation. Every generator-conformance, scientific, security, network, commercial, production, LIVE, frontier, settlement, weight, and emission authority remains unearned.
