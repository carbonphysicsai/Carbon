# B-07S: Exact v2 research-service protocol

**Wave:** B

**Map ref:** `WAVE-B/B-07S`

**Status:** DONE

**Target phase:** WB-2

## What and why

Ratify the exact v2 operation set, wire types, lifecycle, errors, canonicalization, bounds, and local-adapter contract.

An architecture diagram cannot guarantee interoperable or fail-closed service behavior. Downstream implementations need one exact protocol owner.

## What it adds

One exact local carbon_research_v2 contract: twelve operations, closed wire types and bounds, deterministic task lifecycle and prior identity, structural fixture capability, and one semantic owner per operation.

## Explicit non-goals

It does not implement B-07A-G, alter carbon_protocol_v1, authorize public prior publication, or grant a network listener, credentials, real identity, production signing, quoting, qualification, production service, or LIVE.

## Current stage

B-07S is done under its OWNER-DX-03 shipping predicate in bounded SPECIFIED / RATIFIED protocol scope. It freezes the exact local v2 wire, lifecycle, prior identity, context capability, disclosure, and single-owner composition contract without implementing B-07A-G. B-07A is next, todo, and unstarted.

## Maturity ceiling

B-07S earns SPECIFIED / RATIFIED only. Runtime implementation/testing and scientific, security, network, commercial, production, and LIVE qualification remain unearned.
