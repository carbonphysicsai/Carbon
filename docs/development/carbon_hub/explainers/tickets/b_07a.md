# B-07A: Interaction manifest and shared v2 primitives

**Wave:** B

**Map ref:** `WAVE-B/B-07A`

**Status:** DONE

**Target phase:** WB-3

## What and why

Implement shared v2 protocol primitives, the sole ratified InteractionManifest wire resource, and public research-capability discovery.

Clients need to know which bounded research operations a Challenge supports and which exact contracts, limits, and versions govern them.

## What it adds

One exact shared nominal and canonicalization core, ChallengeInfo and InteractionManifest resources, immutable exact-version discovery store, and bounded local adapter for two discovery operations.

- **Depends on:** B-02A, B-02B, B-02C, B-05, B-07R, B-07S, A3, A9
- **Feeds:** B-07B, B-07C, B-07D1, B-07E, B-07G, B-E4, B-GATE
- **Driver:** Codex
- **Review route:** Protocol + security
- **Master questions:** MQ-005, MQ-006, MQ-015, MQ-016, MQ-017, MQ-024

## Explicit non-goals

It does not expose official v1 submit or result operations, execute the other ten frozen v2 operations, compose the full dispatcher, or create capabilities that the Challenge has not registered.

## Current stage

B-07A is done under its OWNER-DX-03 shipping predicate in bounded IMPLEMENTED / TESTED shared-core and discovery scope. It adds the exact shared v2 vocabulary, ChallengeInfo, the sole InteractionManifest wire resource, immutable historical discovery, and a local two-operation adapter. B-07B is next, todo, and unstarted.

## Maturity ceiling

B-07A earns IMPLEMENTED and TESTED only for the shared v2 nominal core, discovery resources, immutable exact-version store, and local two-operation adapter. Full-service conformance and every qualification remain unearned.
