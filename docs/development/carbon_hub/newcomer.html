Built in bounded scope

Wave A — Build the trustworthy software foundation

What are we building? Build the basic software boundaries Carbon needs before it can run a real scientific competition: define safe submissions, protect hidden tests, score by fixed rules, separate private evidence from public results, and track failures cleanly.

Why does Carbon need it? Later science is only credible if the software keeps competitors, evaluators, protected test information, public outputs, and economic state from silently taking control of one another.

Done when: Carbon can demonstrate the intended boundaries with controlled test fixtures and automated checks.

Still not true: This does not mean Carbon has a scientifically qualified exam, a live Bittensor market, production security, or real emissions.

What are we building? Define exactly how one physics problem is described, how test cases are created, what counts as a reference answer, how a candidate is measured, and how researchers can practice against the system.
