# Motor public Graphite scoring (DEVELOPMENT)

`electric-motor-magnetics` has a named Level 0 `ChallengeScoring` adapter for
Graphite's public practice path. It compiles the existing declarative
kernel-ridge strategy, stages Motor's pinned public TRAIN and PRACTICE inputs,
runs the fixed CPU worker, and scores predictions on Carbon's host with
`carbon.motor.practice.score_practice`. PRACTICE labels remain host-side.

The adapter does not change Motor's provisional exam gates, components,
normalization, thirty practice cases, aggregate, or existing scaffold. Its
comparison with the scaffold is a descriptive paired mean error difference on
common scorable cases. It reports the number of pairs and the important group
separately, with no confidence interval and `promotable: false`. It cannot
establish population reliability or engineering decision value.

The fixture run proves the named dispatch, synthetic scoring path, host/pod
digest agreement and clean reconstruction. It launches no paid pod and uses no
private pool, counted GetDP case or fresh confirmation set. Motor's private
validator remains unavailable; Graphite's phase-4 verification-pod rebuild
remains a separate NOT_RUN seam. A real Graphite campaign, scientific score
adoption, qualification and LIVE authority each need their own applicable
approval and evidence.
