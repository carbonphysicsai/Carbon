# Prospective public targeted-artifact binding

GRAPHITE-TARGET-BINDING-01 adds `public_target_v1` as an explicit operator
mode for the battery Level-4 development adapter. It binds software evidence
to one vetted public Constructor v3 export. Loading that export validates
bytes and producer-independent construction metadata. It does not train a
model, qualify a graph, exercise a worker or establish mainnet parity.

The operator supplies all three inputs:

```sh
python -m carbon.agent_campaign.graphite.phase4 run \
  --root /absolute/new-run-root \
  --challenge battery-fastcharge-ageing-development-v1 --level 4 --dry-run \
  --public-target-root /absolute/vetted-public-exports \
  --target-bundle candidate-export \
  --target-manifest-digest sha256:<independently-recorded-manifest-bytes-digest>
```

The example is a command form, not execution authority or an actual target.
The public root is trusted operator configuration for an approved public
export, never a miner tool field or a public/executed Boolean supplied by the
candidate. The operator must not point it at controller roots, private data,
protected material, a sealed bank or a holdout. No original private source is
opened to make a public export in this slice. Live execution retains every
existing grant, key, accepted-lane, headroom and host-owner requirement.

The target directory name is one closed component. The manifest's byte digest
must match the separately supplied pin before additional files are read.
The loader accepts exactly the current delivery v3 file inventory plus its
Level-4 envelope. It enforces bounded reads, regular single-link files and
byte digests through no-follow directory descriptors, including every root
ancestor. Absolute/traversal selectors, symlinks, hardlinks, special files,
extra paths, protected names and incomplete bindings refuse with closed
codes. Windows-native intake is unavailable; the POSIX interface fails closed
on unsupported hosts. This engineering boundary is not security acceptance.

Captured bytes are immutable. The public import root and original directory
are never reopened by a rebuild. Existing staging checks resolve the envelope
and graph documents by digest; the current registered metadata rebuild checks
the construction contract and built record. The normalized record binds the
base construction contract separately from the L4 variant digest, the
Challenge id/version, submission digest and built-artifact identity. Numeric
retraining tolerances and scientific adequacy remain unavailable.

The same validated TargetBinding reaches the brief, session pin, verifier,
report, specimen and resume. Returned JSON/workspace views are copies.
Ordinary mappings and direct stand-in construction do not mint that binding.
A same-artifact export with a different manifest is a different target pin;
it cannot silently replace a session or specimen. Replay requires the exact
saved target pin in addition to the independently recorded knowledge snapshot.

Targeted iteration/coverage/specimen schemas are prospective. Existing family
sessions, old schemas and historical evidence retain their meaning. A family
run still reports its research-path attempts. Targeted reports carry the
public target pin and separately state `target_runtime_verdict: UNDETERMINED`
and zero targeted scored attempts. An old unbound record does not acquire
targeted meaning by adding a flag or reminting its specimen.

NoVerifyPods remains the live backend. Targeted model judgement has no trusted
worker/rebuild evidence source, so missing evidence stays UNDETERMINED and
unscored; a session receipt, ordinary pod mapping, GPU/executed label or
diagnostic fixture cannot close the seam. Existing exposure, infrastructure
and miner-local isolation findings retain their original path semantics.
Target binding does not suppress or triage an actual escape.

The `remint` command can receive the same public-target inputs, plus explicit
`--challenge` and `--level`, for an already authenticated targeted source.
Its target must also match the iteration log, session pin and recorded
verdict. Remint reconstructs metadata and formats a diagnostic specimen;
it makes no new oracle, worker or classification decision. This slice cannot
produce an accepted targeted runtime breach/hold without a real backend.

Tests use only the registered TEST_ONLY control inventory and synthetic public
stage bytes. Actual same-entrypoint miner/carrier/worker/replay/disclosure
tests, trusted runtime/fresh/GPU evidence, D4 and historical aggregate evidence
remain full-ticket/host-owner work. Role audit v3 rebinds source prospectively;
immutable audit v1/v2 and the current-source stale-pin control remain intact.
